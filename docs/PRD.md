# 📄 Product Requirements Document (PRD)

## Product Goal
Build an automated, production-ready AI Interview Agent that conducts real-time technical interviews, evaluates candidate answers, and outputs structured feedback reports.

## Core Features
1. **Candidate Roster & Selection**: Browse official candidate profiles and launch custom technical evaluations.
2. **Interactive Interview Room**: Progress timer, question counters, multiline answer textareas, and progress sidebars.
3. **Structured Feedback Dashboard**: Circular score indicators, strengths, gaps, recommended learning actions, and PDF exports.
4. **API Integration**: Single standardized `POST /api/interview` endpoint for backend/LLM turn management.
